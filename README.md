# Tank Factory
## 基本信息
- 参考自[战车工厂](https://github.com/fEndman/WarFactory)，[幻影坦克工厂](https://github.com/TankFactory/Mirage_Colored)
- **本应用仅供交流学习，禁止用于违法用途。用户因不当使用本软件所造成的一切后果由用户自行承担责任。**
- release版本默认只打包arm64-v8a库
## 功能&计划
- [x] 幻影/无影坦克查看和修改
- [x] 图片加解密
- [ ] 更多图片功能
- [ ] 跑路
